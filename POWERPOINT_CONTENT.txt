SLIDE 2: PROJECT OVERVIEW
======================================================================

What is Campsite Commander?

• Android mobile application for managing camping gear inventory
• Helps users track what they've packed before a camping trip
• Simple, intuitive interface with three navigation screens
• Built with Kotlin programming language
• Uses standard Android Views (XML layouts)

Target Users:
  - Campers and hikers
  - Outdoor adventure enthusiasts
  - Anyone who needs to pack for a trip

======================================================================
SLIDE 3: FEATURES
======================================================================

Key Features:

1. Splash/Welcome Screen
   - Branded entry point with campfire icon
   - "GET STARTED" button to enter the app

2. Main Dashboard
   - Shows total number of packed items
   - Quick-action buttons for gear management

3. Gear Management (Detail View)
   - Select from 8 predefined gear items
   - Add categories (e.g., Shelter, Food, Tools)
   - Add quantity/comment for each item
   - Save, view, and clear items

4. Data Operations
   - Save individual gear items
   - View all saved items at once
   - View comments attached to items
   - Clear all data with one tap

// 8 predefined gear items

Operations:
  • Save:     saveCurrentItem(index) → stores input in arrays
  • Load:     loadCurrentItem(index) → fills inputs from arrays
  • Display:  displayItems() → shows all items with details
  • Comments: displayComments() → shows quantity/comments
  • Clear:    btnClear → resets all arrays to empty strings

SLIDE 14: HOW TO BUILD & RUN
======================================================================

Prerequisites:
  • Android Studio (latest version)

SLIDE 15: CHALLENGES & SOLUTIONS
======================================================================

Development Challenges Faced:

1. White Screen on Launch
   Problem: Theme.AppCompat theme requires appcompat library
   Solution: Switched to platform theme
             (android:Theme.Material.Light.NoActionBar)

2. Material Components Not Loading
   Problem: MaterialButton, MaterialCardView failed to inflate
   Solution: Replaced with standard Button, FrameLayout +
             custom XML drawable backgrounds

3. Duplicate Button IDs
   Problem: Same IDs across included layouts caused conflicts
   Solution: Unique IDs per screen
             (btnViewAllItems, btnClearAll vs btnItems, btnClear)

4. XML Namespace Errors
   Problem: android:context → not a valid Android attribute
   Solution: Changed to tools:context with tools namespace
